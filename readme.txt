PROJECT NAME: PHONE BOOK APP
APPROACH: singly linked list & file handling

HOW TO COMPILE:
1. open terminal inside your project folder(named with your ID).
2.type 'make' and press enter to compile all modules

HOW TO EXECUTE:
1.type './phonebook' and press Enter

MENU OPTIONS:
-C/c : Create a new contact(supports multiple numbers and emails via Y/y or N/n prompts)
-P/p : Prints all existing contacts
-F/f : Find a contact by name
-D/d : delete a contact by name
-E/e : Edit an existing contact by name
-S/s : Save all contacts into record.txt
-Q/q : Quit the application
